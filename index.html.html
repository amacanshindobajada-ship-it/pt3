How to run the Shoe Shop locally

Purpose: Get a new teammate running the project in about 15 minutes.

  1. Install Python and Git.
  2. Clone the repository: git clone <repo-url>
  3. Install the requirements: pip install -r requirements.txt
  4. Start the server: python manage.py runserver
  5. Open localhost:8000 in your browser. You should see the shop’s home page.
